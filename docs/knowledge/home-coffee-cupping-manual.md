# 在家杯測操作手冊：從準備、破渣到記錄風味

這份手冊是給剛開始做杯測的人使用。目標不是第一次就打出專業分數，也不是猜中供應商寫的水蜜桃、佛手柑或白花，而是用固定方法把不同豆子、不同烘焙鍋次的差異喝清楚，讓結果可以回頭幫助烘焙覆盤。

本文以 Specialty Coffee Association（SCA，精品咖啡協會）現行的 Coffee Value Assessment（CVA，咖啡價值評估）為基準，再另外標出適合一個人在家執行的簡化方式。家用簡化法可以用來學習與比較，但不等於正式的 SCA 評估。

## 先回答 ZP6 要用多少刻度

如果你用的是目前販售的 **1Zpresso ZP6 Special**，先把杯測起始刻度設為：

> **ZP6 `5.5`，也就是從正確零點往粗的方向轉 55 格。**

這個 `5.5` 是本專案的建議起點，不是 1Zpresso 公布的「官方杯測刻度」。推導依據是：

- SCA 現行標準要求杯測粉比一般紙濾滴濾略粗，並以美規 20 號篩網驗證粒徑分布。[SCA-102 第 5.2.3 節](https://sca.coffee/s/AW_SCA-102_Sample-Preparation_281024_Secured.pdf)
- 1Zpresso 官方把 ZP6 Special 的手沖起點放在約 `4.0-5.0`，官方刻度圖則把法式濾壓壺放在約 `5.0-6.0`。[1Zpresso 研磨刻度說明](https://1zpresso.coffee/grind-setting/)
- 因此先用兩者之間、偏粗側的 `5.5` 做杯測，是合理且容易重複的起點；但它仍要靠你的實機零點與篩網結果驗證。

你先前使用的 `4.8` 不是「不能杯測」，但它仍在官方手沖建議區間內；依官方區間推論，它比杯測目標偏細的可能性較高，沒有過篩前仍不能斷定實際粒徑分布。若要讓之後不同鍋次更容易比較，建議從這份手冊開始統一用 `5.5`，並在紀錄中寫明「未經篩網驗證」或「已經篩網驗證」。

### `5.5` 到底怎麼看

ZP6 Special 每一圈有 `90` 格，每個數字之間有 `10` 格；數字越大，研磨越粗。`5.5` 的意思是從零點往粗的方向轉到數字 `5`，再多 `5` 格，總共 `55` 格，不是轉五圈半。官方標示的每格 `0.022 mm` 是刀盤移動量，不能直接理解成咖啡粉顆粒直徑。[ZP6 Special 官方產品頁](https://1zpresso.coffee/zp6/)、[ZP6 Special 官方使用說明](https://1zpresso.coffee/manual-k-en/)

### 先確認零點，再談刻度

1Zpresso 把零點定義成「手把開始出現旋轉阻力」的位置，不是把調整環用力鎖到最緊。操作時：

1. 確認磨豆機內沒有咖啡豆。
2. 往細的方向慢慢轉，並輕輕測試手把。
3. 手把剛開始出現阻力時停止，把這裡當作零點。
4. 不要再用力鎖緊，也不要在零點附近硬轉手把，避免刀盤互磨。
5. 從這個零點往粗的方向數到 `5.5`。

如果拆洗重組後零點改變，應先重新校正；否則今天的 `5.5` 可能不等於下次的 `5.5`。

### 有 20 號篩網時，這樣驗證最準

SCA 的目標不是某一台磨豆機的刻度，而是讓 `70-75%` 的咖啡粉通過孔徑 `850 µm` 的美規 20 號標準篩網。驗證方式如下：

1. 確認篩網標示為美規 `No. 20`、孔徑 `850 µm`；只寫「20 目」但沒有孔徑的產品不一定相同。
2. ZP6 設為 `5.5`，研磨 `10.0g` 咖啡。
3. 用固定的動作與時間過篩，例如水平晃動 `30` 秒；每次都用同一方法。
4. 秤通過篩網的咖啡粉。
5. 通過量在 `7.0-7.5g`，就落在 SCA 目標範圍。
6. 通過量超過 `7.5g`，代表小於 `850 µm` 的比例太高，下一次往粗調。
7. 通過量少於 `7.0g`，代表大顆粒比例太高，下一次往細調。
8. 每次先調 `0.2`，也就是兩格，再用相同方法重測。

上述水平晃動 `30` 秒是為了建立家中可重複的篩分條件，不是 SCA 指定的篩分手法或時間。

沒有篩網時不用停止杯測。先固定 `5.5` 做至少三次，所有樣品都用相同刻度；不要因為某一杯偏苦或偏淡，就立刻把烘焙結果全部歸咎於研磨。

## 杯測是什麼

杯測（cupping）是把咖啡直接浸泡在杯中，依固定粉水比例、研磨、水溫與時間聞香和品飲的方法。它刻意減少濾杯、注水手法與流速造成的差異，讓注意力回到咖啡本身。

杯測適合回答：

- 同一支豆的第六鍋和第七鍋，哪一鍋酸質更明亮、甜感更完整？
- 某一鍋的苦味是整體都有，還是只有個別一杯出現？
- 咖啡從熱到冷，花果香、甜感、口感和尾韻怎麼改變？
- 下一鍋應該先驗證發展不足、烘焙過深，還是批次不均勻？

杯測不適合單獨證明某個烘焙操作一定造成某種風味。應先記錄杯中事實，再搭配 Artisan 曲線、豆色、失重率、烘焙氣味與多鍋結果提出假設。

## 第一次要做哪一種杯測

| 用途 | 每個樣品的杯數 | 適合情境 | 證據限制 |
| --- | ---: | --- | --- |
| 居家入門比較 | `1` 杯 | 咖啡量有限，先學會流程 | 不能判斷單杯缺陷是否代表整鍋；另一天要重測 |
| 烘焙覆盤 | `3` 杯 | 比較同豆不同鍋，兼看均勻性 | 適合本專案的主要做法 |
| 正式描述性杯測 | `3-5` 杯 | 依 SCA 方法建立風味描述 | 要完整控制杯器、水、研磨與環境 |
| 正式情意評估 | `5` 杯 | 評估品質印象、喜好與均勻性 | 不是初學階段的必要目標 |

SCA 現行標準在使用杯測法做描述性評估時，每個樣品使用 `3-5` 杯；做情意評估時使用 `5` 杯。家裡只有一個人時，可以先做每個樣品一杯，但應清楚標成「居家簡化比較」，不能把單杯結果當成正式品質結論。[SCA-102 第 7.5 節](https://sca.coffee/s/AW_SCA-102_Sample-Preparation_281024_Secured.pdf)

第一次建議只比較 `2-3` 個樣品。SCA 標準建議單場不要超過 `6` 個樣品；初學者一次喝太多，味覺疲勞會比樣品數量更快增加。

## 器材清單

必要器材：

- 相同材質、形狀與容量的耐熱玻璃杯或陶瓷杯。
- 可讀到 `0.1g` 的電子秤。
- 1Zpresso ZP6 Special。
- 可控制溫度的熱水壺。
- 計時器。
- 至少兩支深湯匙或杯測匙。
- 一杯熱水，專門沖洗湯匙。
- 樣品代碼紙、筆與杯測紀錄。
- 托盤或毛巾，因為水會加到接近杯緣。

建議增加：

- 美規 20 號、孔徑 `850 µm` 的篩網。
- 溫度計，第一次確認你的杯子大約何時降到 `70°C`。
- 吐杯，避免一次喝進太多咖啡因。
- 每個樣品一支專用移液湯匙，以及每人自己的品飲匙或小杯。

## 杯子容量與咖啡重量

現行 SCA 標準使用容量 `200-350 mL`、杯口直徑 `75-90 mm` 的強化玻璃或陶瓷杯，並要求同一場的杯子一致。咖啡重量依「杯子裝到杯緣的實際容量」計算，不是看杯底標示的商品容量。[SCA-102 第 5.2.1-5.2.2 節](https://sca.coffee/s/AW_SCA-102_Sample-Preparation_281024_Secured.pdf)

先把空杯放上秤歸零，再用常溫水裝到杯緣。水的克數可近似當成杯子容量，接著用下式計算：

```text
咖啡重量（g）＝杯子裝到杯緣的容量（mL）× 0.055
```

| 杯子實測容量 | 每杯咖啡重量 |
| ---: | ---: |
| `200 mL` | `11.0g` |
| `220 mL` | `12.1g` |
| `250 mL` | `13.75g`，實作可秤 `13.8g` |

本專案先前使用的 `8.25g 咖啡 / 150g 水` 保留了相同粉水比例，可以繼續作為省豆的居家簡化法。不過，現行 SCA 是依 `200-350 mL` 杯器的杯緣容量計算豆重，並注水到杯緣；原配方如果不是用符合規格的杯器裝到杯緣，就不能標成完整的現行 SCA 準備法。若要按現行標準準備，可改用實測 `200 mL` 的杯子與 `11.0g` 咖啡。

## 水要怎麼準備

第一次先固定使用同一款沒有異味的過濾水或瓶裝水，不要每次換水。SCA 現行可接受範圍是：

| 項目 | SCA 可接受範圍 |
| --- | ---: |
| 氯 | 無 |
| 鈣硬度 | `50-175 ppm CaCO₃` |
| 鹼度 | 約 `40-70 ppm CaCO₃` |
| pH | `6-8` |

只知道總溶解固體（TDS）數字，不能完整判斷水是否適合；硬度、鹼度與氯都會影響杯中結果。家裡暫時沒有水質報告時，先以「沒有氯味、沒有明顯礦物味、每次使用同一款」為實作底線。[SCA-102 第 7.4 節](https://sca.coffee/s/AW_SCA-102_Sample-Preparation_281024_Secured.pdf)

注水時的水溫設為 `93°C`。SCA 允許範圍為 `93 ± 3°C`，但學習比較時不要每次在整個範圍內任意變動。[SCA-102 第 7.3 節](https://sca.coffee/s/AW_SCA-102_Sample-Preparation_281024_Secured.pdf)

## 杯測前的準備

### 樣品條件要一致

- 比較不同烘焙鍋次時，盡量使用相同烘後天數。
- 同一場使用同一款水、相同杯子、相同粉水比例與相同研磨刻度。
- 不要一杯用 `4.8`、另一杯用 `5.5`，再把差異全算成烘焙造成。
- 先把供應商風味資料收起來，完成自己的紀錄後再對照。
- 樣品用隨機代碼，例如 `314`、`628`、`951`，不要直接寫第六鍋、第七鍋。要做到真正盲測，可請另一個人編碼與換位，或事先隨機排列並把對照表封存到揭曉時再看。

SCA 對生豆樣品烘焙的正式做法是烘後靜置 `8-24` 小時再杯測。本專案若要觀察自烘豆的養豆變化，可以在第 `1` 天與第 `8` 天各做一次，但兩次要分開記錄；第 `8` 天的結果不能倒填成第 `1` 天就已經存在的風味。[SCA-102 第 5.1.3 節](https://sca.coffee/s/AW_SCA-102_Sample-Preparation_281024_Secured.pdf)

### 環境要簡單

- 桌面清潔，室內不要有香水、精油、油煙或食物味。
- 杯測前避免重辣、口香糖、香菸與味道很重的飲料。
- 準備常溫飲用水；需要時用原味蘇打餅乾休息味覺。
- 咖啡很熱，聞香和啜吸時不要急著把臉或嘴靠得太近。

### 研磨順序

每一杯分開秤豆、分開研磨，並盡量靠近注水時間。更換樣品前，用下一個樣品的少量咖啡清掉磨豆機內前一支豆的殘粉，再正式研磨。所有待比較的樣品必須使用相同刻度；如果要研究研磨刻度本身，應另外開一場測試。

## 一次照著做的完整時間軸

下面把 SCA 允許的 `3-5` 分鐘破渣區間固定成 `4:00`，讓居家紀錄更容易比較。

| 時間 | 操作 | 觀察重點 |
| --- | --- | --- |
| 注水前 | 研磨後立刻聞乾粉 | 乾香強弱、花果、堅果、香料、烘焙味或異味 |
| `0:00` | 以 `93°C` 熱水加到杯緣，開始計時 | 固定順序快速完成各杯，注水時自然產生輕微擾動 |
| `0:00-4:00` | 不碰粉層，聞表面形成的咖啡渣殼 | 記錄濕香；不要提前攪拌 |
| `4:00` | 破渣約三次，同時靠近聞香 | 記錄破渣瞬間釋放的香氣 |
| 約 `4:15` | 撈掉表面咖啡渣、油脂與泡沫 | 不要攪動或挖起杯底沉粉 |
| 約 `8:00` 起 | 咖啡降到約 `70°C` 後開始第一輪 | 先看整體風味與明顯缺陷；實際時間依杯器與室溫調整 |
| 約 `12:00-15:00` | 第二輪，咖啡溫熱 | 酸質、甜感、口感與平衡通常更容易分辨 |
| 約 `18:00-25:00` | 第三輪，接近或低於體溫 | 尾韻、乾淨度、澀感與冷掉才出現的缺陷 |

SCA 要求破渣前維持 `3-5` 分鐘，破渣時攪動約三次；撈渣後要等咖啡降到約 `70°C` 才開始入口評估，並隨降溫至少進行三輪。[SCA-102 第 6.2-6.3 節](https://sca.coffee/s/AW_SCA-102_Sample-Preparation_281024_Secured.pdf)

### 乾香怎麼聞

乾香（fragrance）是熱水加入前，研磨咖啡粉的氣味。

1. 研磨後盡快聞。
2. 鼻子靠近杯口，但不要吸到咖啡粉。
3. 可以輕搖杯子讓氣味集中，也可以不搖；選定後每杯一致。
4. 先寫「強或弱、乾淨或混濁、偏花果或偏堅果」，不必急著猜特定水果。

### 注水與濕香怎麼聞

把 `93°C` 的水加到杯緣，粉層會在表面形成一層渣殼。先聞沒有被打破的渣殼；這和破渣時衝出的香氣一起構成濕香（aroma）的觀察。

多杯同時測時，照固定順序連續注水，並記住順序。不要為了追求速度而把水灑進其他杯，也不要刻意大力沖散粉層。

### 破渣怎麼做

1. `4:00` 時把鼻子保持在安全距離，靠近杯面。
2. 湯匙從靠近自己的一側伸入表面渣殼。
3. 平穩向前攪開，總共約三次。
4. 同時聞蒸氣帶出的香氣。
5. 每一杯破渣前，先用熱水沖洗湯匙。

不要把破渣做成猛烈攪拌。目的是打開渣殼並釋放香氣，不是把杯底沉粉重新攪起來。

### 撈渣怎麼做

破渣完成後，用一到兩支湯匙輕輕帶走表面浮著的咖啡渣、泡沫與部分油脂。湯匙只走表面，不要一路挖到杯底。

杯底留有沉粉是正常的。品飲時從液面上層取樣，不要用湯匙刮杯底。

### 啜吸怎麼做

啜吸的目的，是讓少量咖啡霧化並分散到舌頭與上顎，同時增加鼻後嗅覺對香氣的感受。

1. 湯匙舀約三分之一到二分之一杯匙的咖啡。
2. 先確認溫度不會燙傷。
3. 用短而有力的吸氣把咖啡吸入口中，讓液體散開。
4. 停一兩秒感受風味、酸、甜、苦與口感。
5. 吐掉或吞下少量都可以；樣品多時建議吐掉。
6. 湯匙接觸下一杯前，先用熱水沖洗。

一開始不會發出很大的啜吸聲沒有關係。先做到「每杯用同一方法，而且不燙傷」；熟悉後再增加霧化程度。

多人共飲時，建議每個樣品使用專用湯匙，把咖啡移到每個人的個人湯匙或小杯，再從個人器具啜吸，不要讓入口過的湯匙直接回到公杯。這也是 SCA 標準列出的衛生修改方式。[SCA-102 第 7.6 節](https://sca.coffee/s/AW_SCA-102_Sample-Preparation_281024_Secured.pdf)

## 每一輪要喝什麼

不要第一口就找十個風味詞。每輪只處理幾個問題：

### 第一輪：熱，約 `70°C`

- 整體香氣是強還是弱？
- 有沒有明顯焦、煙、藥水、霉、土或其他異味？
- 樣品之間最大的差異是什麼？

### 第二輪：溫

- 酸是強或弱、尖銳或圓潤？
- 甜感是清楚、微弱，還是被苦味蓋住？
- 口感是薄、滑順、稠厚、粗糙還是乾澀？
- 先選水果、花香、甜香、堅果可可、香料、植物等大類。

### 第三輪：涼

- 尾韻長或短？乾淨或混濁？
- 酸甜是否還在，還是只剩苦澀？
- 有沒有熱時被遮住、冷後才出現的缺陷？
- 這杯的客觀特徵是什麼？你個人喜不喜歡？

「喝到什麼」和「喜不喜歡」要分開記。SCA 現行 CVA 也把描述性評估與情意評估分開：前者記錄咖啡有哪些感官特徵，後者才記品質印象與個人或市場偏好。[SCA Coffee Value Assessment](https://sca.coffee/value-assessment)

如果需要查風味大類，可在完成第一輪自由紀錄後，再打開專案的 [SCA 咖啡風味輪互動指南](../tasting/sca-flavor-wheel-guide.html)。先從大類往內縮，不要拿著最內圈詞彙逐個猜答案。

```markdown

## 固定條件

- 樣品與烘後天數：
- 每個樣品杯數：
```

## 怎麼把杯測連回烘焙覆盤

順序固定成三層：

1. **事實：**例如「第六鍋在溫熱時甜感較高，三杯都出現較長尾韻」。
2. **可能原因：**例如「可能跟中段熱量、一爆後發展或終點焙度不同有關」。
3. **下一次驗證：**例如「下一鍋只微調一爆前的一個火力步驟，其餘條件固定」。

不要直接寫成「發展時間長，所以尾韻一定比較長」。如果同一鍋只有一杯有藥水味或明顯發酵異味，先考慮單顆瑕疵或批次不均勻；如果三杯都有相同方向，才比較能支持整鍋層級的判讀。

回填到 `review.md` 時，至少保留：

- 杯測日期與烘後天數。
- 隨機代碼與揭曉結果。
- 杯數、杯量、粉量、水溫與水源。
- ZP6 零點狀態、刻度，以及是否經 20 號篩驗證。
- 熱、溫、涼三輪觀察。
- 事實、可能原因與下一鍋單一驗證項目。

## 常見錯誤

| 常見做法 | 問題 | 改法 |
| --- | --- | --- |
| 把 V60 試喝直接叫做標準杯測 | 注水、濾紙與流速增加變因 | V60 紀錄標成沖煮試喝；杯測另用浸泡法 |
| 每個樣品用不同杯子 | 容量和降溫速度不同 | 使用同款杯，先量杯緣容量 |
| 只寫 `8.25g`，不管杯子大小 | 粉水比例會改變 | 依杯緣容量乘 `0.055` 算粉量 |
| 把 ZP6 轉到最緊當零點 | 可能卡住或傷刀盤，刻度也失真 | 以手把剛出現阻力的位置為零點 |
| 把每格 `0.022 mm` 當成粉徑 | 刀盤位移不等於實際顆粒尺寸 | 用 20 號篩網驗證分布 |
| 同場一杯用 `4.8`、另一杯用 `5.5` | 無法知道差異來自烘焙還是研磨 | 同場固定刻度；研磨測試另開一場 |
| 水一沖完就喝 | 容易燙傷，高溫也不利辨識 | 撈渣後等到約 `70°C` 再開始 |
| 只喝一輪 | 錯過降溫後的甜感、尾韻與缺陷 | 至少喝熱、溫、涼三輪 |
| 先看供應商風味詞 | 容易被答案提示 | 先盲記大類，揭曉後再對照 |
| 一杯結果就決定大改烘焙 | 單杯可能受瑕疵豆或操作誤差影響 | 三杯或跨日重測，再提出單一調整 |

## 第一次實作的最短版本

如果現在就要開始，照這組條件做：

- 比較同一支豆的 `2-3` 個烘焙鍋次。
- 先做每個樣品 `1` 杯；若結果要拿來正式調整下一鍋，改做每個樣品 `3` 杯或另一天重測。
- 使用相同、實測到杯緣為 `200 mL` 的杯子。
- 每杯 `11.0g` 咖啡。
- ZP6 Special 確認零點後設 `5.5`。
- 水溫 `93°C`，加水到杯緣。
- `4:00` 破渣三次，隨即撈除表面浮渣。
- 降到約 `70°C` 開始，至少喝熱、溫、涼三輪。
- 先記酸、甜、苦、口感、尾韻、乾淨度與風味大類，最後才寫喜好。
- 同場不要改研磨、水溫或粉水比。

做完後，第一個要問的不是「我有沒有猜中風味」，而是：「我能不能在不知道答案時，穩定說出這幾杯哪裡不同？」
